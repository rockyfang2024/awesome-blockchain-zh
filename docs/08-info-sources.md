## 使用这些信息源时

1. 先确认文章日期、作者和原始出处。
2. 对版本、性能、损失金额、监管状态等会变化的数据，保留核对日期和来源。
3. 对攻击归因，分别记录“谁作出的判断”和“证据是什么”；不要把媒体标题当成官方结论。
4. 社交媒体账号可能改名或被冒充，因此这里优先链接可验证的项目站点、文档和发布页。
