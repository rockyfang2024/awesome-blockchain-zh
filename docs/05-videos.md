# 交互练习与开发课程

> 优先选择有明确练习目标、能在本地或沙盒中验证结果的课程。外部课程的内容和版本可能调整，开始前查看课程自己的先修要求。

## EVM / Solidity

| 资源 | 适合 | 形式与结果 |
|---|---|---|
| [Ethereum 官方教程](https://ethereum.org/developers/tutorials/) | 希望按主题补知识的开发者 | 社区教程目录，可按难度、主题和时长筛选 |
| [Speedrun Ethereum](https://speedrunethereum.com/) | 想边做项目边学 dApp 的人 | 一组循序渐进的构建挑战，完成后有可展示项目 |
| [Ethernaut](https://ethernaut.openzeppelin.com/) | 已掌握 Solidity 基础、想练合约安全的人 | 浏览器安全闯关；针对故意脆弱的合约练习 |
| [Damn Vulnerable DeFi](https://www.damnvulnerabledefi.xyz/) | 想学习 DeFi 安全的人 | 本地化挑战环境；先理解每关目标和隔离要求 |

## Solana

| 资源 | 适合 | 形式与结果 |
|---|---|---|
| [Solana 官方 Quickstart](https://solana.com/docs/intro/quick-start) | 刚开始写 Solana 程序的人 | 浏览器或本地快速入门，跟随文档部署和调用程序 |
| [Anchor Quickstart](https://www.anchor-lang.com/docs/quickstart) | 选择 Anchor 的 Rust 开发者 | 通过 Anchor 创建、构建和测试第一个程序 |
| [Solana Bootcamp](https://solana.com/developers/bootcamp) | 想系统学习 Solana 概念和实战的人 | 官方课程入口；按自己的程度选择模块 |

## Bitcoin

| 资源 | 适合 | 形式与结果 |
|---|---|---|
| [Bitcoin and Cryptocurrency Technologies](https://www.coursera.org/learn/cryptocurrency) | 想系统学习 Bitcoin 与密码货币基础的人 | Princeton 课程；课程开放情况以 Coursera 页面为准 |
| [Learn Me a Bitcoin](https://learnmeabitcoin.com/) | 喜欢图解和小例子的学习者 | 交互式解释 Bitcoin 交易、脚本与数据结构 |

## 安全练习约定

- 只在课程提供的挑战、测试网或本地环境中练习；不要把真实私钥导入陌生网站。
- 不向课程网站输入主网助记词，也不为“领取测试币”支付费用。
- 课程若要求安装依赖，先读仓库说明并检查来源；工具版本应与课程版本对应。
