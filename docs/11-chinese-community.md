# 开发者社区与技术信息源

收录可公开访问、能帮助开发者定位技术问题或参与开源的入口。社区帖子是讨论材料，不等同于官方文档或安全结论；涉及资产、合约部署和事件归因时要回到一手来源核实。

## 问答与技术讨论

- [Ethereum Stack Exchange](https://ethereum.stackexchange.com/) — EVM、智能合约及以太坊开发问答。
- [Bitcoin Stack Exchange](https://bitcoin.stackexchange.com/) — Bitcoin 协议、脚本、节点和钱包开发问答。
- [Solana Stack Exchange](https://solana.stackexchange.com/) — Solana 程序与客户端开发问答；Solana 官方开发者资源页也将其列为支持入口。
- [Ethereum Magicians](https://ethereum-magicians.org/) — 以太坊改进提案和协议设计讨论。提案讨论不代表已被采用。
- [LearnBlockchain](https://learnblockchain.cn/) — 中文区块链技术文章、问答与教程社区；检查文章发布日期、作者和引用资料。

## 官方社区入口与参与

- [Ethereum 社区入口](https://ethereum.org/community/) — 官方整理的线上社区、活动与参与方式。
- [Ethereum 如何参与](https://ethereum.org/community/get-involved/) — 开发者可从文档、开源项目、开发者会议和 ETHGlobal 活动入手。
- [Solana 开发者资源](https://solana.com/docs/tools) — 官方文档、Cookbook、课程、程序示例与 Stack Exchange 支持入口。
- [Bitcoin 开发者文档](https://developer.bitcoin.org/) — 官方开发指南和文档问题反馈入口。
- [ETHGlobal 活动](https://ethglobal.com/events) — 黑客松与开发者活动日历；活动时间、形式和参与条件以主办方页面为准。

## 如何提问，怎样判断答案

提问时附上链/网络、工具版本、可复现步骤、错误原文和最小代码片段；不要贴私钥、助记词、访问令牌或未脱敏的生产日志。优先确认回答是否链接到官方文档、源码、标准或可复现测试。涉及资金损失、漏洞或攻击者身份时，区分已确认事实、第三方调查和推测。

*最后核对：2026-10-12。活动和社区入口可能变化，请以主办方或项目官方页面为准。*
